One-time setup needed

This tool's shared state row doesn't exist in Supabase yet, and the app can't create it itself (blocked by row-level security). Run this once in the Supabase SQL editor, then reload this page:

insert into app_settings (key, value)
values ('cue_light_event', '{"light":"off","matches":[],"updatedAt":null}'::jsonb)
on conflict (key) do nothing;
