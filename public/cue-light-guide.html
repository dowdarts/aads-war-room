●Overview

Cue Light & Schedule is a two-screen signalling tool: one device is the Controller (whoever is running the floor presses Start, Wait, or Off), and a second device is the Display (a big, simple light on a screen near the players/scorekeepers, showing exactly what the controller pressed). Both stay in sync automatically over the network — there's no cable between them.

The same uploaded schedule also drives push notifications to two other apps in this suite: the Players Portal (tells players when they're called, when their match goes live, and when doors open) and the Score Keepers Portal (tells scorekeepers when their match goes live or the schedule changes). You don't need to do anything extra for those — they ride along on the same Controller actions.

Everything is organized by event — if more than one event exists, you'll be asked which one this device is working on before you see anything else.

1.Role & Event Selection

This is what you see the very first time the app is opened on a device.

Choosing a role

Tap 🎛️ Controller if this device is the one being used to press Start / Wait / Off. Tap 🚦 Display if this device is the one being pointed at the floor showing the big light and schedule. The app remembers your choice — it won't ask again on this device unless you tap Switch role later.

Choosing an event

If there's exactly one event set up, the app skips straight past this and opens it automatically. If there's more than one, you'll see a list — tap the one you're running. If there are none yet, type a name and tap + Create New Event.

Like the role, the event choice is remembered on this device. Use Switch event in the header any time to pick a different one (useful if the same tablet is reused across multiple tournaments).

2.Controller — Lights & Schedule

The main working screen for whoever is running the floor.

The three buttons

Three big buttons sit at the top: ▶ Start, ✋ Wait, and ⏹ Off. Tap one and it lights up (with a glow matching its colour) to confirm it's the active state — and the Display screen updates within about a second to show the same thing.

  • ▶ Start — tells the Display to show a green GO light. Also pushes a "match is live" notification to the Players Portal and the Score Keepers Portal for whoever's involved in the current match.
  • ✋ Wait — tells the Display to show a red WAIT light. No portal notifications fire for this one — it's a floor-only signal.
  • ⏹ Off — tells the Display to go dark (no label shown at all).

Marking a match complete

Below the buttons is the Event Schedule — every match from the uploaded CSV, in order. The next match that hasn't been checked off is automatically marked Up Next with an orange border. Tick a match's checkbox once it's finished:

  • Completed matches grey out and get a line through the name, so the list visually shrinks to what's left.
  • Checking a box also sends a "you've been called" notification to that match's two players on the Players Portal, and sets it as the current match — which is what Start uses to figure out who to notify as "live" and who's "up next."
  • Unchecking a box just un-marks it — it doesn't undo the notification that already went out.
Order matters. Check off the match that just finished before you press Start on the next one — that's how the app knows which match is "live" for the scorekeeper and player push notifications.

3.Display — The Big Light

This is the screen that actually faces the players/floor — set this device's role to Display, then leave it alone.

A large coloured panel fills the top of the screen: green with a GO label for Start, red with WAIT for Wait, and plain dark with no label for Off. It updates automatically whenever the Controller changes state — nobody touches this screen during play.

Below the light is the same Event Schedule list as the Controller (read-only here — no checkboxes to tap), so anyone standing near the Display can also see what match is up next.

Don't tap Switch role on this device by accident. Doing so drops it back to the role-selection screen and the light disappears until someone re-selects Display.

4.Uploading the Schedule

Controller-only — Upload Event Schedule (CSV), above the schedule list.

One CSV file — the same AADS TOC officials schedule export used elsewhere — drives everything: the match list shown on both Controller and Display, and every scorekeeper/caller/floor-control shift used by the Score Keepers Portal. There's nothing left to upload separately, and nothing that can drift out of sync, because both come from the very same rows.

  • Any row with both a Player A and Player B filled in becomes a match in the schedule list.
  • Any named official in that row (Main Caller, Main Score Keeper, Back Up Score Keeper, Back Up Caller, Floor/Player Control, Relief/Equipment Support) becomes a shift for that person, linked to the same match.
  • Names listed in the "On Break" column become a break shift, not tied to any match.
  • Rows with no players at all (setup, reset, standings breaks, etc.) are skipped from the match list but officials in them still get a personal shift.

Uploading a new file when matches or shifts already exist asks you to confirm first — it tells you exactly how many matches/shifts it's about to replace and how many the new file contains, since this replaces the whole schedule, it doesn't merge.

5.Alerts & Kill Switches

Three independent toggles in the Controller header — each one a master switch for a different audience.

ToggleWhat it silences
🔔 Cue Light AlertsPush notifications sent to any device subscribed to the cue light itself, whenever Start or Wait is pressed.
🔔 Players Portal Alerts"You're called" / "match is live" / "doors are open" pushes sent to the specific players involved.
🔔 Score Keepers Alerts"Match is live" / "schedule updated" pushes sent to whoever is on a scorekeeper/caller/floor shift for that match.

Each one flips between ON (normal colour) and OFF (shown in red) independently — turning one off does not affect the other two, since they go to different audiences and you may only want to quiet one of them at a time (e.g. mute Score Keeper pings during a quiet stretch while players still get called).

This is a real kill switch, not just a per-device mute. Turning a toggle off stops that category's pushes for every device, even ones where a person has notifications enabled on their own phone — the check happens on the server before anything is sent, not just in this browser tab.

Doors Open

🚪 Doors Open in the header sends a one-time notification to every signed-in player that the event has started and doors are open. It asks you to confirm before sending, since it goes out to the entire player list at once, not just whoever's in the current match. It's covered by the Players Portal Alerts toggle — if that's off, this button won't actually push anything.

6.Floating the Display (Picture-in-Picture)

Display screen only — lets the light keep floating on top of other apps.

Tap 🪟 Float to pop the light out into a small floating window using Picture-in-Picture, so it stays visible even if you switch to another app on the same device. The button changes to 🪟 Floating… while active.

Why this exists: a browser tab that gets pushed into the background can be throttled by the OS, which would otherwise freeze the light on stale data. Floating keeps it live and visible without needing to babysit the tab.

If Float isn't available (Picture-in-Picture isn't supported in this browser), you may instead see 🧭 Open in Safari to Float — this only shows up on an iPhone where the app is running inside Chrome, since iOS only grants the floating video feature to Safari itself, no matter which browser app icon you tapped.

★Tips & Troubleshooting

  • Controller and Display not matching? Give it a second or two — both screens poll for changes roughly twice a second, so there's a brief lag, not a sync failure.
  • Want notifications even with the app closed? Tap 📲 Add to Home Screen first, then 🔔 Enable Alerts (Display screen) — on iPhone, notifications and the home-screen install go hand in hand; a plain Safari/Chrome tab can never show them, only the installed icon can.
  • Switched role or event by mistake? Just tap the role/event buttons again — your schedule and light state aren't lost, they live on the server tied to the event, not the device.
  • Multiple devices? Schedule, light state, and shifts are all saved to the cloud, not the device — any Controller or Display signed into the same event sees the same thing.
  • Re-uploading a schedule mid-event? Double-check the confirmation dialog's match/shift counts before accepting — it fully replaces what's there, so re-uploading an old or wrong file will wipe completed checkmarks too.
  • Score Keepers or Players not getting notified? Check that the relevant alert toggle in the Controller header is set to ON — all three are independent and easy to mix up.

📋Light Cheat Sheet

LightUse it when…
▶ Start (Green / GO)The match is ready to begin — players should start play now. Also notifies the Players Portal and Score Keepers Portal that this match is live.
✋ Wait (Red / WAIT)Hold play — something needs sorting out on the floor before this match can start or continue. Floor-only signal, no portal push.
⏹ Off (Dark, no label)Nothing currently active on this board — between matches, end of session, or before the event has started.

The Display always mirrors whatever the Controller last pressed — there's no separate "set" step.
